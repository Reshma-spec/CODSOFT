# Movie Rating Prediction using Python

## Project Overview

This project predicts movie ratings based on movie attributes such as genre, director, actors, duration, votes, and release year.

The objective is to analyze historical IMDb movie data and build a machine learning model capable of estimating movie ratings accurately.

## Dataset

IMDb Movies India Dataset

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Machine Learning Algorithm

* Random Forest Regressor

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Handling Missing Values
4. Exploratory Data Analysis
5. Feature Engineering
6. Model Building
7. Model Evaluation
8. Feature Importance Analysis

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

## Features Used

* Genre
* Director
* Actor 1
* Actor 2
* Actor 3
* Duration
* Votes
* Release Year

## Outcome

Successfully built a regression model that predicts movie ratings and identifies the factors influencing movie success and audience ratings.
